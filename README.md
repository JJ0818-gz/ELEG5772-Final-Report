# ELEG5772 Final Report

四人课程项目：音频降噪。Diffusion 或 Flow Matching 尚未确定。

## 项目结构

- src/denoising/：数据处理、模型、训练和评估
- configs/：实验配置
- scripts/：运行脚本
- notebooks/：探索分析
- docs/：方案、分工与实验记录
- report/：报告与图表
- data/：本地数据，不上传原始音频
- outputs/：本地权重、日志和生成音频，不上传

## 协作

本仓库公开，任何人可查看、下载、Fork，并通过 Pull Request 提议修改。直接推送需要仓库负责人在 Settings → Collaborators 中邀请账号。

GitHub Desktop：Clone repository → 拉取 main → New branch → 修改并 Commit → Publish branch / Push origin → Create Pull Request → 组员审阅后合并。

不要上传密码、令牌、未获授权的数据或大型模型权重。确定方法后补充依赖版本、数据获取步骤和可复现实验命令。
